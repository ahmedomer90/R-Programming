# Data Directory

This folder contains small metadata files required to reproduce the analyses.

## Included

- `taylorGrps(Sheet1).csv`
  - Tumour subgroup annotation used during the first-year PhD methylation analyses.

## Excluded

The following large dataset is intentionally excluded from Git:

- `GSE85217_M_exp_763_MB_SubtypeStudy_TaylorLab.txt` (~268 MB)

This file is a downloaded public dataset and can be obtained again from its original source. It is omitted to keep the Git repository lightweight and within GitHub's file size recommendations.
